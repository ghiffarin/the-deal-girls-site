# Photos

Drop photos in this folder using these exact names. JPG, PNG or WEBP all work.
Until a file is here, the site shows the striped placeholder.

| File name            | Where it shows                  | Best size / shape        |
|----------------------|---------------------------------|--------------------------|
| hero.jpg             | Top of the page, right side     | 1200 × 1500 (portrait)   |
| founder.jpg          | Founder section, Ayesha         | 1200 × 1600 (portrait)   |
| city-amsterdam.jpg   | Bridge section, Amsterdam tab   | 1200 × 1000              |
| city-jakarta.jpg     | Bridge section, Jakarta tab     | 1200 × 1000              |
| city-manila.jpg      | Bridge section, Manila tab      | 1200 × 1000              |
| og-image.jpg         | Preview when the link is shared | 1200 × 630               |
| testimonial-1.jpg …  | Testimonial headshots (optional)| 200 × 200 (square)       |

Keep each photo under ~400 KB (squoosh.app is free and makes this easy).
File names are lowercase, no spaces.
