# Logos

Drop logos here with these exact names. SVG is best, PNG with a transparent background also works.
JPG does not work: the site only looks for `.svg` and `.png`.
Until a file is here, the site shows the name as text.

If both `name.svg` and `name.png` exist, the site uses the SVG. So to replace a logo that is
already an SVG, upload the new one as `.svg` too (or delete the old SVG).

Logos on the dark "Who we've worked with" strip (partners page) are shown in cream automatically,
whatever colour the file is.

Only add a logo if you have permission to show it.
